# Regavo — 浏览器 2D 即时战略游戏

[English](../../README.md) | [Tiếng Việt](../vi/README.md) | **简体中文**

Regavo 是在桌面浏览器中与 AI 对战的单人即时战略原型。可选择罗马、蒙古、波斯、唐朝、奥斯曼或大越，并经历定居、军事、帝国三个时代。

摧毁敌方城镇中心即可获胜；双方城镇中心在同一模拟步被摧毁则为平局。原型已具备完整对局流程，竞技平衡和发行性能仍需进一步实战测试。

![Regavo 中的大越聚落、采集资源的村民，以及迎战蒙古骑兵的战象与火炮](../images/daiviet-gameplay.jpg)

_帝国时代（III）的大越聚落，村民正在耕作、伐木和采金，各类兵种与蒙古军队交战。游戏内演示战斗截图，灵感来自陈朝抗击元蒙的胜利。_

## 本地运行

需要 **Node.js 22.13 或以上**及 **pnpm 12.8.1**，版本要求见 `package.json`。按 [pnpm 官方指南](https://pnpm.io/installation)安装后，在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm audit:licenses
pnpm dev
```

打开 Vite 输出的网址。开发服务器会持续占用该终端。许可证生成命令记录本机平台实际安装的依赖，并排除依赖图之外的残留包。`pnpm-lock.yaml` 是唯一依赖锁文件。

在第二个终端执行完整检查：

```sh
pnpm exec playwright install chromium
pnpm validate
```

构建静态发行版本并本地预览：

```sh
pnpm exec playwright install chromium
pnpm build
pnpm exec vite preview --host 127.0.0.1
```

将 `dist/` 部署在网站根路径。游戏无需 API 密钥或应用后端，模拟与 AI 在 Web Worker 中运行。

生产构建只包含运行时图片及必要的回退图集，使用无损 WebP，保留每个像素、尺寸和透明度。历史 PNG 与来源记录留在仓库中。`dist/asset-manifest.json` 记录源文件和输出的哈希；构建后运行 `pnpm check:assets` 会核对所有解码 RGBA 像素。首次构建编码图片，后续构建复用 `node_modules/.cache/regavo-assets/` 的内容寻址缓存。`public/_headers` 中的 Cloudflare 缓存规则适用于带哈希的图片和代码包。

构建时使用对局模型生成首页全景，要求每个单位均有原画精灵。18 个场景提供 960/1920 px 无损 WebP。首页只下载选中的场景，并在悬停/聚焦时预取；进入对局或工坊后才加载完整精灵图。首次构建需要 Playwright Chromium（`pnpm exec playwright install chromium`）。场景缓存位于 `node_modules/.cache/regavo-previews/`，检查哈希并在原画、渲染器或工具链变化时自动重新生成。

## 可玩内容

- 食物、木材、黄金、石料四种资源。村民采集、狩猎并将货物送至有效仓库；携带者死亡时货物丢失。
- 建造、维修、农田、训练队列、集结点与时代升级。每方人口上限为 200；波斯和大越战象最多六头，包括训练队列。
- 六个文明的单位阵容与机制：罗马盾阵、蒙古移动营地、波斯贸易、唐朝生产模式、奥斯曼火炮部署和大越民兵动员。
- 96×96 地图、三种地形、三级 AI、仅显示当前视野的战争迷雾、小地图、暂停、游戏速度及浏览器/JSON 存档。仍可读取旧版 64×64 存档。
- 模型工坊可查看单位、建筑、自然物、动作和朝向。音乐与音效通过 Web Audio 合成。
- 越南语、英语和简体中文界面。手动选择会保存；未选择时优先采用 Cloudflare 检测的访问者国家（VN → 越南语，CN → 简体中文，US/GB/AU/NZ/IE → 英语），其次采用浏览器首个受支持语言，最后回退为英语。Worker 在界面启动前将国家信息写入 HTML；本地 Vite 开发使用浏览器语言。

## 操作

| 操作                      | 输入                                         |
| ------------------------- | -------------------------------------------- |
| 选择                      | 左键单击或拖动框选                           |
| 增减选择；追加命令        | Shift + 单击；Shift + 右键                   |
| 移动或与目标交互          | 右键；普通移动会中断战斗，直至到达目的地     |
| 攻击移动                  | A，然后左键选择目的地                        |
| 撤退                      | D，然后左键选择目的地                        |
| 停止 / 切换原地坚守       | S / H                                        |
| 选择空闲村民              | I                                            |
| 设置 / 选择编队           | Ctrl/Cmd + 1–9 / 1–9；双按数字将镜头移至编队 |
| 聚焦所选单位或城镇中心    | F                                            |
| 触控板平移 / 缩放         | 双指滚动 / Ctrl/Cmd + 滚动或捏合             |
| 拖动地图                  | Space/Alt + 拖动，或启用地图拖动按钮         |
| 旋转墙段或城门 / 连续放置 | R / Shift + 单击                             |

离开未结束对局或按浏览器后退会打开确认框并暂停对局。可留下、保存后退出或不保存退出；确认退出后返回首页。每 30 秒及标签页转入后台时自动保存。刷新/关闭标签页警告由浏览器 `beforeunload` 控制，可能需要先发生用户交互。导出 JSON 可在其他设备恢复存档。

## 开发

`pnpm validate` 依次执行 lint、格式、类型、许可证、测试和生产构建。单独命令为 `pnpm lint`、`pnpm format:check`、`pnpm check`、`pnpm check:licenses`、`pnpm test`、`pnpm build`。`pnpm lint:fix` 和 `pnpm format` 可应用自动修复。

依赖变更或在不同 OS/CPU 上重新生成记录后，运行 `pnpm audit:licenses`，再运行 `pnpm check:licenses`。自动生成的声明和美术清单不参与 Prettier 格式化。`pnpm clean` 清理可重新生成的构建/缓存；`test-results/` 是本地 QA 证据目录，Git 会忽略它。

| 路径                                | 用途                                               |
| ----------------------------------- | -------------------------------------------------- |
| `src/game/`                         | 数据、文明参数、模拟、寻路及 AI；固定 20 Hz 模拟步 |
| `src/render/`                       | PixiJS 场景、图集选择、几何、镜头及战斗效果        |
| `src/ui/`、`src/i18n/`              | React 菜单/HUD/工坊与翻译                          |
| `src/audio/`                        | 原创合成音频                                       |
| `tests/`、`scripts/`                | 回归检查与美术/许可证工具                          |
| `src/assets/`                       | Vite 导入的界面背景图                              |
| `scripts/data/`                     | 美术测量与校准工具的输入数据                       |
| `docs/`、`public/art/`、`licenses/` | 文档、运行时美术及许可证记录                       |

## 原型限制与权利

尚无在线多人、战役、水战、驻军、军事科技树或拖动连续筑墙。四个预留出生点不代表已实现四队模拟。局部避让无法保证锁定阵型，AI 尚未主动使用全部文明技能。

美术源图提供四个对角朝向，其余方向使用最近朝向。大越有完整行走姿势及独立木材/黄金/石料/肉类货物图集；其他文明的货物表现各有差异。尚缺完整死亡动画、建筑损坏图及所有单位的分时代制服。未认证总计 400 个单位时的目标性能。
